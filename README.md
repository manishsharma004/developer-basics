# Cabo Help

Single-page React reference for **Cabo** power-card abilities (the forwarded house-rules cheat sheet).

## Commands

```bash
bun install
bun run dev      # http://localhost:5173
bun run build
bun run preview
```

## Abilities covered

| Cards | Effect |
|-------|--------|
| 7, 8 | See your card |
| 9, 10 | See another player's card |
| J, Q | Unseen swap |
| K (black) | Seen swap |
| K (red) | −1 / penalty |
